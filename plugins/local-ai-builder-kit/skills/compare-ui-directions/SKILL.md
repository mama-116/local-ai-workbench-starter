# 画面案を比較する

## 手順

1. 対象画面と、その画面で利用者が完了したい行動を確認する。
2. 既存画面、デザイン規約、参考画像があれば先に確認する。
3. `references/comparison-format.md` に従い、構造の異なる3案を作る。
4. 各案に、適する利用者、採用理由、最も強い反論を添える。
5. 利用可能な画像生成機能で各案のモックを別々に作る。
6. モックを見せ、選択または組み合わせを依頼する。
7. 選択前に本実装を始めない。

## 制約

- 色違いだけを別案として数えない。
- 機能一覧を1画面へ詰め込まない。
- 専門用語より、利用者が次に押す場所を明確にする。
- 選択された案と理由をADRまたは設計書へ記録する。

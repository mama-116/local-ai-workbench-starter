# 作業スレッドを案内する

## 判断

`references/thread-policy.md` を読み、まず同じスレッドで継続できないか確認する。

新しいスレッドを提案するのは次のいずれかに該当するときだけにする。

- 目的または成功条件が変わった。
- 独立してレビュー・完了判定できる別成果物へ移る。
- 現在の会話では重要な決定を安定して参照できない。
- 利用者が明示的に分離を求めた。

設計から実装へ移るだけでは分けない。

## 引き継ぎ

新しいスレッドを提案するときは、利用者に整理作業をさせず、次を含む貼り付け可能な引き継ぎ文を作る。

- 目的
- 完了したこと
- 決定と理由
- 未決
- 参照成果物
- 次の一手1つ

Issueがある場合は引き継ぎ文へリンクするが、Issue操作を前提知識にしない。

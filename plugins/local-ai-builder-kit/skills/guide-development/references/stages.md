# 開発段階

| 段階 | 入口 | 出口 |
|---|---|---|
| discovery | 作りたい結果が曖昧 | 問題、利用者、成功条件が言える |
| scope | 機能が増え続ける | 初版でやらないことが固定された |
| options | 手段が複数ある | 決定または見直し条件付き仮置きがある |
| visual | UIの見た目や操作が未決 | 選択済みモックがある |
| contract | API、DB、状態が未定義 | 契約と異常系が文書化された |
| implementation | 契約とテストがある | 最小実装がテストを通る |
| verification | 動くが完了証拠がない | 完了条件とレビューを満たす |
| handoff | ゴール変更または独立成果物へ移る | 引き継ぎ文と次の一手がある |

段階を飛ばさない。ただし既に出口条件を満たす証拠があれば再作成しない。

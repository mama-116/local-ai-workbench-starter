# Local AI Workbench Starter

Codexとの会話を中心に、ローカルLLMアプリを段階的に開発するためのスターターキットです。
会話、RAG資料、実行ログをローカルに保つことを既定とし、Ollamaを利用するWindows向けチャットアプリを同梱しています。

# ADR-0020: シーン・キャスト型グループ会話と確認段階付き正史記憶を採用する

- Status: Accepted
- Date: 2026-07-18
- Decision owner: 利用者

## Context

ZETA AIのように、複数キャラクターを名前付きの別吹き出しで登場させ、利用者の文章から即席の登場人物も場面へ参加させたい。一方、長期会話を要約とプロンプトだけで維持すると、初対面、関係、好み、健康上の制約などをモデルがもっともらしく捏造または上書きし、利用者の信頼を損なう。

管理を強くしすぎると、記憶候補の確認が会話を何度も遮り、物語への没入を損なう。群像劇の把握、記憶の信頼性、日常操作の軽さを同時に満たす境界が必要である。

## Decision

- 1会話の正式キャラクターは最大5人、ナレーターは別枠とする。
- 利用者の入力に現れた人物は、出典に結び付くシーンゲストとして正式枠と分離し、同時に最大5人まで扱う。
- 通常ターンはOllamaへの1回の要求で複数話者を生成し、順序付き発言を `TurnBatch` として扱う。
- 会話要約とは別に、出典、時点、分岐、知識範囲、承認状態を持つ構造化された正史記憶を設ける。単純な現在値の上書きにしない。
- シーン状態は自動更新する。明示された低リスク情報は自動保存して非モーダルUndoを提示する。健康、秘密、関係の重大変更などは現在の応答へ反映しても、長期保存は確認待ちにする。推測、仮定、引用、対象不明は自動保存しない。
- UIはC案のシーン・キャスト型を基本にし、A案の非モーダルUndo通知を組み合わせる。単独会話では会話集中型へ簡略化する。

状態値とデータ境界は、契約確定後に [ARCHITECTURE.md](../ARCHITECTURE.md) を正本とする。詳細と未決事項は [GROUP_CHAT_DESIGN.md](../GROUP_CHAT_DESIGN.md)、3案比較は [GROUP_CHAT_UI_OPTIONS.md](../GROUP_CHAT_UI_OPTIONS.md) を参照する。

## Alternatives

| 案 | 判定 | 理由 |
|---|---|---|
| 単独キャラクターを維持する | 不採用 | 群像会話の目的を満たさない |
| 人数分を逐次生成する | 初期版では不採用 | 最大5人で待ち時間とVRAM負荷が増え、話の重複も起きやすい |
| 記憶をすべて自動保存する | 不採用 | 誤推測、対象人物の取り違え、機微情報の過剰保存に弱い |
| 記憶をすべて事前確認する | 不採用 | 会話が頻繁に中断され、日常利用の負担が大きい |
| シーン型UI＋段階付き保存 | 採用 | 群像劇の状況把握、秘密管理、会話の没入感を両立しやすい |

採用案への最も強い反論は、1回生成では各キャラクターの独立性が弱く、右側パネルが会話領域を圧迫することである。発言の同質化が継続する場合は限定的な追加生成を比較し、右欄利用率が20%未満、または狭さへの具体的意見が3件以上出た場合は表示構成を見直す。

## Consequences

- 会話生成、記憶抽出、長期保存を分離してテストできる。
- 好みの変化と安全制約を両立し、正史にない質問へ「記録がない」と答えられる。
- 秘密と分岐の知識範囲が必須になり、データモデルと漏えいテストが増える。
- 最大5人でも通常1回生成に抑えられるが、出力検証と話者名解決が必要になる。
- 右側パネルの利用価値を実測し、単独会話の操作性を回帰確認する必要がある。

## Acceptance criteria

- 最大5人の正式キャラクターと別枠のナレーター、最大5人のシーンゲストを境界値で検証できる。
- 1回生成の複数発言が名前付きの別吹き出しになり、再生成・分岐時に `TurnBatch` の整合性を保つ。
- 「以前の好み」「現在のアレルギー」「現在の一番の好み」を別イベントとして保持し、安全制約を優先できる。
- 推測、引用、対象不明を自動保存せず、機微情報を未確認のまま長期記憶へ確定しない。
- 秘密と別分岐の記憶が、知らないキャラクターの生成文脈へ入らない。
- 低リスク記憶のUndo、確認待ち候補の承認・却下、単独会話の回帰が画面試験で確認できる。
- RTX 5060 Ti 16GB基準で追加モデルをロードせず、同じ出力トークン上限の5人会話が単独会話比で生成速度20%以内の低下、ピークVRAM 16GB以内に収まる。

## Review condition

記憶イベント契約、秘密・分岐の漏えいテスト、5人時の生成時間を実測した時点で再確認する。重大な誤記憶または秘密漏えいが1件でも再現した場合、機能拡張を止めて記憶取得境界を修正する。

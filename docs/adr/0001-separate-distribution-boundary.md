# ADR-0001: 個人アーカイブと配布キットを分離する

- Status: Accepted
- Date: 2026-07-16
- Decision owner: 配布者

## Context

個人アーカイブと過去プロジェクトには、会話ログ、秘密情報、非公開コード、再配布条件の異なる資産が含まれる。一方、配布キットは一般ユーザーへZIPで渡す。

## Decision

配布キットを独立したリポジトリにする。過去資産は棚卸し後、出典、利用範囲、機密性を確認したものだけを移植する。生ログやDBを参照する実行時依存は作らない。

## Alternatives

- `soma-archive`内に配布フォルダーを作る: 誤同梱の影響が大きいため却下。
- ZIP生成時だけ除外する: 除外設定の失敗が一度で漏えいにつながるため却下。

## Consequences

- 配布境界とGit履歴が明確になる。
- 資産を再利用するたびに移植判断が必要になる。

## Review condition

見直しなし。共有ストレージを導入する場合も、配布リポジトリからPRIVATEデータへ直接到達させない。

# ADR-0022: ゴミ箱内の会話を確認付きで一括完全削除する

- Status: Accepted
- Date: 2026-07-23
- Decision owner: 利用者
- Supersedes: ADR-0003の「初版は物理削除を行わない」というスコープ制限

## Context

会話のゴミ箱移動と復元は実装済みだが、利用者が不要なローカル会話データをアプリ内から除去できない。完全削除は復元できず、会話に従属する監査・正史記憶・派生データを取り残す危険がある。

## Decision

ゴミ箱内に表示した全会話のID集合を、別確認後の1回のSQLite transactionで完全削除する。通常一覧の会話はRepositoryで拒否し、表示後に対象集合または状態が変化した場合は部分削除しない。画面は復元操作と分離した危険領域を採用する。

正史記憶の追記専用制約は通常操作で維持し、完全削除transactionへ束縛された一時ガードがある場合だけ、対象会話に所属する正史記憶の削除を許可する。

## Alternatives

- ゴミ箱移動だけを維持する: 利用者が不要データを除去できないため却下。
- 1件ずつ完全削除する: 安全だが、一括削除を初回から必要とする利用者判断を満たさないため却下。
- 選択式の削除管理を作る: 柔軟だが初回の操作と状態管理が増えるため却下。

## Consequences

- 利用者はゴミ箱内のローカル会話データを一度に除去できる。
- 完全削除後は会話、本文、派生データ、監査を復元できない。
- 共有キャラクター、モデル設定、RAG文書は削除対象から分離する必要がある。
- 新しい会話従属表を追加するときは、完全削除transactionと試験の更新が必要になる。

## Review condition

一部だけ残したい要望が発生した場合は選択式を再検討する。削除後のSQLite容量が日常利用を妨げる場合だけ、安全な空き領域回収を別設計する。

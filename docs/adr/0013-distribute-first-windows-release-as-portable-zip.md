# ADR-0013: 初回Windows版をポータブルZIPで配布する

- Status: Accepted
- Date: 2026-07-17
- Decision owner: 利用者

## Context

初版を別のWindows PCで試せる形にする必要がある。インストーラーは導入体験に優れる一方、更新方式、署名、管理者権限、アンインストール時のデータ保持まで同時に決める必要がある。また、開発時のFlet保存領域には個人の会話DBが存在し、配布物への混入を確実に防がなければならない。

## Decision

- 初回配布は `Local LLM Chat` という表示名のWindows 11 x64向けポータブルZIPとする。
- 利用者はZIPを展開し、`LocalLLMChat.exe` を直接起動する。インストールと管理者権限を要求しない。
- 会話、設定、接続先、ログはFletが提供するWindowsの利用者専用データ領域へ保存し、EXEの隣へ保存しない。
- Ollama、モデル、会話DB、接続先設定、ログ、秘密情報は配布物へ同梱しない。
- ビルドでは `.flet`、`.local-data`、開発環境、テスト、既存ビルドを除外する。
- 完成物にDB、ログ、接続先設定、秘密鍵または環境設定が見つかった場合はZIP作成を失敗させる。
- ZIPと同時にSHA-256チェックサムを生成する。
- 初回はコード署名を行わない。Windowsの警告が表示される可能性を配布手順へ明記する。
- カスタムアイコンは正式なブランド検討まで延期し、初回はFlet既定アイコンを使う。

## Alternatives

- インストーラーを先に作る: 導入は分かりやすいが、署名なし配布の警告、更新、削除時のデータ保持まで検証範囲が広がるため不採用。
- EXEの隣へデータを置く: フォルダーごと持ち運べるが、個人データの誤配布と書き込み権限の問題が増えるため不採用。
- ZIPとインストーラーを同時に作る: 利用者の選択肢は増えるが、初回の受入試験と保守対象がほぼ倍になるため不採用。

## Consequences

- 無料で、インストールせずに別PC検証を始められる。
- アプリ更新時にZIPを置き換えても、利用者データは配布フォルダーから分離される。
- Windowsのアプリ一覧、スタートメニュー登録、自動更新は初回に含まれない。
- 未署名EXEのため、Windows Defender SmartScreen等の確認が表示される可能性がある。

## Review condition

別PCでの起動・更新・データ保持が安定し、日常利用者が3人以上になるか、スタートメニュー登録とアンインストールが必要になった時点で、署名とインストーラーを検討する。Windows 10対応の要望が出た場合は、対象範囲を広げる前に実機受入試験を追加する。

# ADR-0003: 書き直しをメッセージ分岐として保存する

- Status: Accepted
- Date: 2026-07-16
- Decision owner: 利用者

## Context

過去の発言を書き直したいが、元の会話とAI回答を失いたくない。本文を上書きすると、その本文を前提に生成された後続発言との整合が崩れ、元の状態を再現できない。

## Decision

メッセージをUUIDと親メッセージUUIDで結ぶ木として保存し、書き直し時は元発言の親から新しいbranchを作る。利用者発言と生成終了後のAI発言は変更せず、生成中のAI発言だけは途中保存のため追記を許す。

## Alternatives

- 書き直しを提供しない: 誤字や条件変更を試すたびに新規会話が必要になるため却下。
- 本文をその場で上書きする: 後続回答の前提と監査履歴が壊れるため却下。
- 分岐時に全履歴を複製する: 読取りは簡単だが、同じ本文が増え、どこまでが共有履歴か不明になるため却下。

## Consequences

- 元の会話を保持し、複数の続きから選べる。
- 履歴表示は親を辿る必要があり、単純な時刻順取得では実装できない。
- 分岐点と現在の続きをUIで分かるように表示する必要がある。
- 初版は物理削除を行わず、不要な会話はアーカイブする。初回リリース後に追加するゴミ箱内全件の完全削除は [ADR-0022](0022-delete-archived-conversations-in-one-confirmed-operation.md) がこのスコープ制限を置き換える。

## Review condition

本人試用で分岐切替が日常会話を妨げる場合、通常画面では分岐表示を隠し、必要時だけ開くUIへ変更する。保存方式そのものは、データ移行試験なしに変更しない。

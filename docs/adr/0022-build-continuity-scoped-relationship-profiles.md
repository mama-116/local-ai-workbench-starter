# ADR-0022: 世界線単位のProfile・関係台帳と説明可能な関係表示を採用する

- Status: Accepted
- Date: 2026-07-26
- Decision owner: 利用者

## Context

現在の正史記憶は会話・分岐・知識範囲を厳密に分離し、秘密漏えいを防ぐ。一方、会話を新しくすると、利用者のProfile、キャラクターとの約束、喧嘩と和解、築いた関係も継承されない。アプリのテーマである「よりリアルな信頼関係構築」には、会話を越える継続性と、別設定を混ぜない隔離の両方が必要である。

利用者は、ユーザーとAIの双方がProfileへ提案・追記できること、「AIが思うユーザーとの関係」、キャラクター別の好感度パーセンテージ常時表示、脈絡のない直接的侮辱と理由のある喧嘩の区別を求めている。

## Decision

- 会話間の共有境界として `continuity`（世界線）を導入する。会話は必ず1世界線に属する。
- 既存会話は移行時に各1件の独立世界線へ割り当て、移行だけで別会話の情報を共有しない。
- ユーザーProfile、合意・設定上の関係、AIが思う関係、好感度・信頼・緊張を分離する。
- AIは候補提案と明示された低リスクProfileのUndo可能な追記だけを行える。利用者確定値の上書き、共有範囲拡大、完全削除は行えない。
- 関係は世界線、利用者Profile、安定キャラクターIDに結び付く追記イベントとし、現在値を決定論的に導出する。
- 関係辞書は複数併存、方向付き役割、過去化、利用者定義を許す。辞書掲載を同意や安全性の根拠にしない。
- 好感度を0〜100%で常時表示するが、信頼、緊張、関係ラベル、AIが思う関係、直近の変化理由を別に保持する。
- モデルにパーセンテージを直接決めさせない。モデル候補をApplication層で再検査し、検証済みイベントをReducerで集計する。
- 引用、仮定、第三者への言及、合意済みロールプレイ、理由のある作中の喧嘩を、脈絡のない直接的侮辱と区別する。
- UIはB案を採用し、全キャストの好感度を上部チップへ常時表示し、選択人物の詳細と理由を右側関係パネルへ表示する。

状態値とデータ境界は [ARCHITECTURE.md](../ARCHITECTURE.md)、詳細、成功基準、撤退条件は [RELATIONSHIP_PROFILE_DESIGN.md](../RELATIONSHIP_PROFILE_DESIGN.md)、初期関係候補は [RELATIONSHIP_TAXONOMY.md](../RELATIONSHIP_TAXONOMY.md) を正本とする。

## Alternatives

| 案 | 判定 | 理由 |
|---|---|---|
| 会話単位の記憶を維持する | 不採用 | 関係が会話作成ごとに初期化される |
| アプリ全体でProfileを共有する | 不採用 | 別世界線、秘密、異なるキャラクターの知識が混ざる |
| 会話全文を引き継ぐ | 不採用 | 分岐境界、削除伝播、コンテキスト上限を制御できない |
| LLMが好感度を直接出力する | 不採用 | 再現性、根拠、二重処理耐性がない |
| 世界線別の追記イベントから投影する | 採用 | 現行の正史・承認・Undoと整合し、共有範囲を説明できる |

採用案への最も強い反論は、関係を数値化して常時表示すると、会話が好感度を上げるゲームへ変わり、利用者の自然な発言を萎縮させることである。そのため、数値だけを関係の正本にせず、理由、信頼、緊張、関係認識を併記し、報酬演出や善悪評価を使わない。

## Consequences

- 会話を分けても、選択した同じ世界線では関係を継続できる。
- 既存会話を独立世界線へ移すため、移行直後の安全境界を維持できる。
- ProfileとAIの解釈の所有者が明確になる。
- 関係イベント、Reducer、完全削除の依存追跡、境界判定のテストが増える。
- 右側パネルの情報量が増え、正史記憶と場面表示を折りたたむ必要がある。
- 性的・支配的・被害関係には、年齢・同意・撤回を扱う別契約が必要になる。

## Acceptance criteria

- 同じ世界線だけが確認済みProfileと関係を継承し、別世界線と秘密の漏えいが0件である。
- 既存会話の独立世界線移行で、移行前後の生成Contextが一致する。
- 好感度変化が出典と理由を持ち、同じイベントの再処理で変化しない。
- 全キャストのパーセンテージを常時確認でき、選択人物の詳細と履歴へ1クリック以内で到達できる。
- AIが利用者確定Profileの上書き、共有範囲拡大、完全削除を実行できない。
- 引用、仮定、文脈付きの喧嘩を関係侵害として保存せず、直接的で脈絡のない侮辱だけを候補化する固定試験が通る。
- Profile完全削除後、対象値が要約、索引、関係解釈、生成Contextへ残らず、元会話の再走査でも同じ項目を復活させない。元会話本文が削除対象外であることを利用者へ事前表示する。

## Review condition

固定シナリオで関係候補の誤判定率、好感度を目的化する利用傾向、右側パネルの利用率を測定した時点で再確認する。秘密・別世界線の漏えい、Profile完全削除後の再出現、利用者への報復・羞恥・操作的誘導が1件でも再現した場合は、関係Contextの生成注入と自動指標反映を停止する。

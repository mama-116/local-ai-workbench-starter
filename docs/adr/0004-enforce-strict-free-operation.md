# ADR-0004: 初版を解除不能な無料運営モードにする

- Status: Accepted
- Date: 2026-07-16
- Decision owner: 利用者
- Superseded in part by: ADR-0006（localhost固定を、確認済みプライベートLANへ拡張）

## Context

初版は有料API、月額サービス、クラウドサーバーを使わず、既存PC上で追加課金ゼロにする。OllamaはlocalhostのAPIからクラウドモデルも実行できるため、接続先をlocalhostへ固定するだけではクラウド利用を防げない。また、無料枠付きサービスは条件変更や上限超過によって将来費用が発生し得る。

## Decision

初版は解除不能な `strict_free` モードだけを持ち、Ollamaのクラウド無効化、ローカルモデル実体確認、外部URL・APIキー拒否、Provider費用区分の既定拒否を重ね、すべての外部機能呼出し前に検査する。

## Alternatives

- 文書で「クラウドを選ばない」と案内する: 誤選択と設定変更を機械的に防げないため却下。
- `:cloud` / `-cloud` というモデル名だけを拒否する: 将来の名称変更や別名に対応できないため単独採用を却下。
- PCの外向き通信をすべてファイアウォールで遮断する: 強い対策だが、モデル取得と将来の明示的なWeb検索まで妨げ、アプリ単体で再現できないため必須条件にはしない。
- 複数の検査を重ねる: 1つの仕様変更だけで課金経路が開かず、テスト可能なため採用。

## Consequences

- 初版からクラウドモデル、有料Provider、無料枠付きAPIを利用できない。
- Ollamaをローカル専用に設定して再起動する準備が必要になる。
- モデル名だけでなく、ローカル実体とOllama設定を確認するテストが必要になる。
- 将来Web検索を追加する場合、費用判定とプライバシー承認を別々に通す必要がある。
- 有料機能が必要になっても初版の解除スイッチは追加せず、別成果物として新しいADRを作る。

## Review condition

利用者が有料サービスを含む別版を明示的に求めた場合だけ見直す。その場合も `strict_free` の既定動作を弱めず、別の配布物または明確に分離された設定として設計する。

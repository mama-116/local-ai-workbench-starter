# ADR-0025: 会話一覧のメニューから会話名を変更する

- Status: Accepted
- Date: 2026-07-26
- Decision owner: 利用者

## Context

会話名は作成時にだけ入力でき、保存済み会話を内容に合わせて整理し直せない。変更操作の候補として、中央見出しでの直接編集、会話一覧の行メニュー、右側設定欄を比較し、利用者が一覧メニュー案を選択した。

## Decision

通常会話の各一覧行へ「会話の操作」メニューを置き、「名前を変更」から専用ダイアログを開く。会話名は前後空白を除いた1〜120文字とし、保存後は一覧と中央見出しをSQLiteの正本から再読込する。メニュー表示後に対象がゴミ箱へ移動された場合は更新を拒否する。

## Alternatives

- 何もしない: 作成後に整理できない問題が残るため却下。
- 中央見出しで直接編集する: 最短操作で発見しやすいが、会話に対する操作を一覧へまとめる利用者の選択と合わないため却下。
- 右側設定欄で管理する: 将来の設定追加には強いが、名前変更だけのために常設面積を使うため却下。

## Consequences

- 会話を開かなくても一覧から変更対象を選べる。
- 操作は行メニューを開くまで見えないため、直接編集より発見しにくい。
- 会話操作が増えた場合は同じメニューへ整理できる。
- ゴミ箱内の会話名は変更できず、一覧へ戻してから操作する。

## Review condition

名前変更を見つけられない利用者報告が3件以上発生した場合は、選択中会話の中央見出しにも編集導線を併設する。会話操作が3種類以上になった場合は、メニュー内の情報設計を再比較する。

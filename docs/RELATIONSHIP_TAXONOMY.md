# 創作・キャラクター関係性辞書

更新日: 2026-07-26

この文書を、初期搭載する関係性候補と分類メタデータの正本とする。状態値、権限、保存境界は [ARCHITECTURE.md](ARCHITECTURE.md)、利用目的と画面方針は [RELATIONSHIP_PROFILE_DESIGN.md](RELATIONSHIP_PROFILE_DESIGN.md) を正本とする。

## 利用規則

- 関係性は1組につき複数併存できる。「友人かつライバル」のような組合せを許可する。
- `元・〇〇` は元の定義を削除せず、過去化イベントと現在の関係イベントで表す。
- 師弟、主従、加害者・被害者のような方向付き関係は、役割Aと役割Bを区別する。
- 辞書の掲載は、行為への同意、倫理的な肯定、安全性、性的内容の許可を意味しない。
- 性的、支配的、監禁、被害を含む候補はAIから自動提案しない。年齢、同意、創作範囲を確認できる別契約ができるまでは、利用者による明示設定だけを確認待ち候補として扱う。
- 辞書外の関係は利用者定義として追加できる。未知の文字列を既存関係へ自動的に近似しない。

## 分類メタデータ

各定義は表示名に加え、次のメタデータを持つ。

| 項目 | 意味 |
|---|---|
| カテゴリ | 画面で候補を探すための大分類 |
| グループ | 類似関係をまとめる中分類 |
| 方向 | `symmetric` または `directed` |
| 役割 | 方向付き関係の役割A・役割B。対称関係では空 |
| 注意タグ | `power_imbalance`、`sexual_or_romantic`、`coercion_or_confinement`、`harm_history`、`identity_or_memory_gap` など |
| 状態 | 現在有効、過去、提案中、利用停止 |

注意タグは生成可否を単独で決めない。Application層が、利用者の明示設定、年齢・同意契約、世界線、キャラクターの境界と合わせて判断する。

## 初期辞書

### 1. 王道・絆

- 共闘・信頼: 幼馴染、相棒（バディ）、親友・盟友、同期
- 育成・継承: 師弟、メンターとメンティ、拾った側と拾われた側
- 憧れ・敬愛: 先輩・後輩、王と騎士、主従関係

物語上の軸は、背中を預ける安心感、技術や意志の継承、忠誠と尊敬である。

### 2. 対立・歪み

- 宿命の対峙: ライバル、宿敵（ネメシス）、因縁、光と影
- 背徳・不義: 浮気・不倫、W不倫、略奪愛、セフレ
- 愛憎・執着: 共依存、クソデカ感情、崇拝、泥沼の三角関係
- 奪取・支配: 寝取られ（NTR）、寝取り（NTL）、監禁と被監禁

物語上の軸は、対立が存在意義になる緊張、モラルとの衝突、執着、奪取と喪失である。描写上の魅力と現実の安全性を同一視しない。

### 3. 現実・社会

- 血縁・婚姻: 親子、兄弟姉妹、夫婦、義理の家族（姻族）
- ビジネス: 上司・部下、同僚、クライアントとベンダー
- 社会・日常: 隣人、店主と客、原告・被告、加害者・被害者

物語上の軸は、血縁・法律・利害・偶然の事件によって生まれる、簡単には切れない接点である。

### 4. 特殊・現代

- 特殊世界観: 創造主と被造物、契約者と悪魔、異種族コンビ
- ネット・現代: クィアプラトニック、配信者とリスナー、ネトゲの相方
- ギャップ・変化: 元・〇〇、両片想い、偽装恋人、元奴隷と元主人

物語上の軸は、寿命や倫理観の差、画面越しの結び付き、時間経過や誤解による関係名の変化である。

### 5. 主従・契約・心理

- 主従・契約: 人質と監視役、囚人と番人、神と生贄、生き神と神職
- 心理・裏切り: 詐欺師とターゲット、共犯関係、被害者と加害者の家族

物語上の軸は、利害不一致と逃れにくい役割、裏切りの予感、複雑な因果の中で生まれる連帯である。

### 6. ファンタジー・特殊設定

- 特殊共有: 憑依者（ホスト）と寄生者、人格共有、転生者と元の世界の知人、原作者とキャラクター
- 神話・運命: 未来を知る者と抗う者（預言者と英雄）、幾度も輪廻転生を繰り返す者同士

物語上の軸は、プライバシーのない近さ、記憶のずれ、メタ視点、決められた結末へ抗う共犯性である。

### 7. 変化球・日常・アウトロー

- 変化・再起: 元ライバル同士の共同経営者、引退ヒーローと元悪の幹部
- 記憶・認知: 「私」を知らない幼馴染、記憶を失った恋人、入れ替わり当事者
- 疑似家族・逃避: 偽りの家族、任務のための夫婦、逃亡者と追跡者、闇社会の裏切り者同士

物語上の軸は、過去の対立を越えた再起、片側だけが持つ重い記憶、演技や利害が本物へ変わる過程である。

## 初期の提案境界

初期版でAIが自発的に提案できるのは、会話本文に明示された低リスク関係だけとする。関係の重大変更、恋愛・婚姻、上下関係、被害・支配・監禁、性的関係は、推測から作らず確認待ちにする。

「AIが思う関係」は辞書の関係名をそのまま断定する値ではない。確認済みの関係、関係イベント、キャラクター設定から「信頼できる親友だと思っている」のような現在解釈を作り、根拠イベントIDと生成に用いたキャラクターバージョンを保持する。
